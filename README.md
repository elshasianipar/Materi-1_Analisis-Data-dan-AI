# Materi 1 — Analisis Data dan AI
## Studi kasus
Analisis data penjualan toko untuk mengetahui total penjualan dan produk dengan nilai penjualan tertinggi.

## Materi yang diterapkan
Data preparation, pemeriksaan data kosong/tidak valid, descriptive analytics, dan pengambilan insight sederhana.

## Cara menjalankan
Pastikan Python 3 tersedia, lalu jalankan:
`python analisis_penjualan.py`

Data CSV yang digunakan adalah data simulasi untuk pembelajaran.
